# Whatsit Swap

A trading table for weird, random, one-of-a-kind things. Built for Aria.

Two traders, one screen. Put your stuff on the table, then:

- **X (More!)** - "that's not enough yet, add something"
- **Check (Ready)** - "I'm happy with this trade"
- **Cancel trade** - clears the whole table, everybody gets their stuff back

Both traders happy at the same time and the stuff swaps.

Every item is randomly generated - a name, a quirk, a rarity (1-5 stars) and its
own serial number, so no two are quite the same. Tap **Find stuff** to dig up more.
Stashes save in the browser.

Single file, no dependencies: `index.html`.
